# 中島聡

## 要点

- Microsoft Windows 95 等の開発経験を持つ実務家。AI時代の日本企業・教育・産業再興を語る参照人物。
- 「AIは第2次産業（素材・部品・光工学）が大チャンス」と主張——第3次ソフト中心企業の危機感と対比する。

## 定義または輪郭

- AI教育は遠回りでもAIに書かせ続ける。今のAIに「ギリ足りない」仕事を頼み、波より1歩先に行く。
