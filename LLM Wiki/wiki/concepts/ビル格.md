# ビル格

## 要点

- 建物に固有の人格・思想・歴史・関係性を LLM で構造化し、意味を語り判断する主体として表現・運用する概念（Building Personality）。
- 不動産をスペック（立地・面積・利回り）から意味（何を守り、誰と関わり、どんな記憶と判断原理を持つか）へ読み替える試み。
- 冷泉荘を起点に、オーナー・管理人・入居者・地域から一次情報を収集し、5階層 Knowledge として編集する。

## 定義または輪郭

- **5階層モデル**
  - 魂: 存在理由、創設者の理念、倫理観（模倣困難度 ★★★★★）
  - 心: コミュニティ文化、暗黙のルール（★★★★★）
  - 記憶: 創設物語、歴史的転換点、集合的記憶（★★★★）
  - 五感: 空間の雰囲気、感性的体験（★★）
  - 身体: 法規、仕様、安全、権限（★）
- **編集パイプライン**: 憲法条文 → 例外規定 → 裁定フロー → 意思決定ログ → 語彙集
- **Chatbot から Agent へ**: 物件固有の価値観で自律的に判断し、文脈と判断履歴を持つ存在へ拡張する。
- **評価軸**: 固有性、一貫性、境界条件、根拠提示、不明回答。最終的には内覧体験、入居、指名検索、メディア、改修説明、他オーナーからの相談など「人とお金が動くか」。

## この wiki で重要な理由

- `0次情報` `意味経済` `テクノアニミズム` `Agentic Engineering` を、不動産という具体領域で接続する実践概念。
- AI 研究の「モデル性能」ではなく「LLM が扱う対象の設計」という、この wiki の知識設計観と直交する。
- 建物に人格を与えることは、ホラー・世界観設計の「気配」「ロア」とも接続しうる。

## 緊張関係 / 異説

- AI 学会の標準的な研究型（大量データ、明確タスク、数理評価）にそのまま当てはめると、概念提案に見えやすい。
- RAG 比較は有効だが主目的ではない。主目的は不動産価値の増幅と社会実装。
- Agent 化のほうが Chatbot 化よりリスクが高い。hallucination が行動へ流れ込む。
