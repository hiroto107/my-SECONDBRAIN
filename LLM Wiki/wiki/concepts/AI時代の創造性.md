# AI時代の創造性

## 要点

- 生成AIを easy button として使うのではなく、意図、観察、実験、内省、選択を通じて人間の創造性を拡張する考え方。
- AI時代の創造性は、生成ボタンを押す能力ではなく、`何を問うか` `どこに摩擦を残すか` `何に反応したか` `何を選ぶか` `どの媒体文法で形にするか` に宿る。
- 出力が大量化・平準化するほど、人間側の価値は、問い、好奇心、編集、キュレーション、0次情報、身体性、Iの矛盾や欲望へ移る。
- 創造プロセスは、AIへの命令ではなく、AIの出力と自分の反応を見ながら往復する動的なループとして扱う。
- AI生成物の評価は、出力の見た目だけでなく、生成過程、起源、物質性、データ、労働、環境負荷、流通形式まで含む問題になる。
- 『思考の整理学』の観点を足すと、AIで出力が速くなるほど、寝かせる、忘れる、複数案を競わせる、身体を通す、編集する工程が人間側の創造性として重要になる。
- 深津貴之の note 入門から見ると、創造性は大作を完成させる力だけでなく、楽しみ続け、発表し続け、外部との関係の中で育てる力でもある。

## 定義または輪郭

- `AI時代の創造性` は、生成AIによって作業実行や初期案生成のコストが下がった後に、人間がどこで創造的主体性を持つかを整理する概念。
- d.school 系 source では、創造の中心は `easy button` ではなく、意図設定、予期せぬものへの傾聴、実験の設計、選択の自覚、媒体への流暢さへ移るとされる。
- Adobe 系 source では、生成AIは制作の技術的障壁を下げる一方、アイデア創出、問題解決、クリティカルシンキング、学び続ける力をより重要にする。
- 原研哉×深津の source では、AIの合理的・統計的な出力に対して、Iの矛盾、欲望、暗黙知、7と8の間の判断を入れることが人間側の役割として示される。
- 久保田晃弘の source では、RLHF や平均美への収束に対し、触覚、ノイズ、不完全さ、歴史の再読が AI時代の美学課題として出る。
- 久保田晃弘の後半 source では、AI生成物を [[LLM Wiki/wiki/concepts/人工物の美学]] として捉え、自然 / 人工、本物 / 複製、人間制作 / AI生成の境界を再検討する。
- 外山滋比古の source では、創造的思考は知識量ではなく、[[LLM Wiki/wiki/concepts/知的発酵]]、[[LLM Wiki/wiki/concepts/忘却]]、編集、第一次的現実に根差した思考として整理できる。

## 基本構造

- **前段の創造**: 問いを立てる、方向を決める、制約を置く、参照する遠い領域を選ぶ。
- **生成中の創造**: AIの出力に耳を傾け、自分の反応を観察し、予期せぬズレを次の問いに変える。
- **後段の創造**: 編集、キュレーション、リミックス、媒体文法への変換、文脈設計を行う。
- **外部化された創造**: 現場、身体、関係性、0次情報、パーソナルブランド、社会資本を通じてAIが持たない材料を入れる。
- **時間差の創造**: 出力を即採用せず、寝かせ、忘れ、再読し、残った違和感や関心だけを次の方向にする。
- **継続発表の創造**: 完成度を理由に止めず、小さく外へ出し、読者や環境との関係の中で次の制作へ回す。

## この wiki で重要な理由

- `AI` `日本文化` `創造性` `身体性` `ホラー` のどれかを横断して接続する足場になる。
- `Jホラー` や世界観制作において、AIは怪物や映像を大量に出す道具ではなく、気配、違和感、物語の余白を探索する相手として使える。
- `AI時代の自己` や `意味経済` と接続すると、創造性は作品制作だけでなく、誰として作るか、どんな関係性や価値を生むかの問題になる。
- `0次情報` や `身体性` と接続すると、AIが平均化しやすい出力に、自分の現場知、感覚、土地、経験を注入する実践になる。

## 緊張関係 / 異説

- AIは創造の民主化と効率化を進めるが、摩擦を消しすぎると、フロー、学習、主体性感覚を弱める。
- 選択肢が増えるほど自由になる一方、choice overload や表面的なスクロール消費が起きる。
- AIを協働相手として使うほど創造は拡張されるが、自分の選択や貢献を見失うと、作品が平均的なAI出力へ寄る。
- パーソナルブランドや関係性が価値になる一方、創造が浅い自己演出に回収される危険もある。

## open question

- 自分の制作工程で、AIに任せてよい作業と、あえて人間が関与し続けるべき判断はどこか。
- AIとの往復で、自分が何に驚き、何を選び、どう方向転換したかをどう記録するか。
- AIの即時出力を、どれくらい寝かせてから再読すると、自分の関心や違和感が見えやすくなるか。
- AIで作ったものを、どの粒度なら楽しく継続発表できるか。
- Jホラー制作において、AIの平均美から外れる `気配` `ノイズ` `身体性` をどう設計するか。
- 自分だけが持つ0次情報やIの矛盾を、どの段階でAIに注入するか。
- AI生成物の制作過程や使用モデルを、どこまで作品の文脈として公開・設計するか。
