# 2026-05-28 Source - AIをEasy Buttonにしない

## 要点

- AIをただ楽にするボタンとして使わず、意図、内省、選択を通じて人間の創造性を広げるべきだと論じるd.school記事。
- 見栄えのいい成果物を素早く出すだけでは、学び、成長、創造の「摩擦」が失われる。創造性には不確実性と向き合い、自分で選ぶ主体性が必要。
- AI時代の創造行為の中核は、生成ボタンを押すことではなく、前段の意図設定と後段の編集・傾聴・リミックスにある。
- カメラやサンプリングの歴史と同じく、新しい道具は創造性を消すのではなく、創造的判断の場所を移動させる。

## 主張

- AIを `easy button` として扱うと、創造に必要なフロー、挑戦、主体性感覚が薄まる。
- 創造性は新しいものに出会うだけではなく、新しいものを意図的に選び、不確実性の中で形づくる行為である。
- 人間の意思決定の場所は、手作業の実行から、問い、方向づけ、編集、キュレーション、リミックスへ移る。
- AIは完成物の自動生成機ではなく、注意力を研ぎ澄まし、人間の創造性が生まれる空間を広げる触媒として使うべき。
