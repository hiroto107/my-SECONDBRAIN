# 2026-06-18 Source - JSAI2026 ビル格と不動産価値の再設計

## 要点

- 2026年度人工知能学会全国大会（第40回、2026-06-08〜12）で、樅山・吉原による「Building Personality: New Frontiers Enabled by Real Estate with Personality（ビル格）」を発表した。
- 発表の中核は、建物をスペック情報の集合ではなく「意味を語り判断する主体」として LLM で表現・運用する `ビル格（Building Personality）` 概念。
- 冷泉荘を事例に、公開情報のみの AI と一次情報を構造化した AI を比較し、後者は「不明を先に言う」「source 付き根拠提示」「判断軸の抽出」が可能になることを示した。
- 学会参加を通じた学びは、ビル格が LLM 性能研究ではなく「LLM が扱う新しい対象を設計する試み」であること、評価軸はモデル精度より「人が動き、お金が動き、関係性が変わるか」であること。
- Agent 化すると hallucination が文章だけでなく行動（入居判断、契約説明、Wiki 更新、外部発信）へ流れ込むため、「禁則・例外・決裁」の条文化が必要。

## 主張

- 不動産評価の限界: 立地・面積・利回りだけでは、建物に蓄積された意味・記憶・関係性・空気感・運営者の思想は捉えきれない。
- 5階層モデル: 魂（存在理由・倫理観）→ 心（コミュニティ文化・暗黙ルール）→ 記憶 → 五感 → 身体（法規・仕様）。模倣困難度は上位ほど高い。
- 差別化は上位2階層（魂・心）に宿る。ここは一次情報であり、公的 DB には記録されない。
- 冷泉荘のビル格化: オーナー吉原氏（魂）、管理人杉山氏（心）、入居者・アーカイブ（記憶）、現地調査（五感）、図面・法規（身体）から収集。編集パイプラインは「憲法条文 → 例外規定 → 裁定フロー → 意思決定ログ → 語彙集」。
- Before/After 比較: Web 情報のみの AI は自信ありげに創作する（演出語、未確認エピソード、質問文の仮定を事実化）。構造化ナレッジ AI は不明を先に言い、source 名で根拠を示し、反例から判断軸を導出する。
- Chatbot → Agent: 情報不足時に AI は黙らず「物語」で埋める。Agent 化するとその物語が行動になり、自律 Agent では間違いが再生産・配布される（「権限を持った hallucination」）。
- 建物 AI 同士の対話: 物件特有の意思決定を持ったエージェント同士が対話すると、単独では見えない判断・運用の差分が浮かぶ。N 個の思想を持つビル格同士の対話は都市計画への接続も示唆する。
- 学会との差異: 一般 AI 研究は大量データ・明確タスク・数理モデル・評価指標が中心。ビル格は少量だが文脈の濃い質的データを Knowledge 構造へ変換する試み。
- ビル格の本質: LLM を新しく作る研究ではない。建物の無形価値を AI が参照・判断に使える Knowledge として構造化し、不動産価値の再設計を行う実践。
- 評価軸の転換: スペック（何を持っているか）→ 意味（何を語れるか）。築年数は減損指標ではなく人格の深みの指標。
- 社会実装: AI の外側（制度、組織、予算、責任分担）を動かす必要がある。ビル格の強みは個別建物から始められること。
- 進め方: 研究 → 実践 → 事業の往復。冷泉荘で価値を生み、AI で拡張し、結果を研究として記述する。
