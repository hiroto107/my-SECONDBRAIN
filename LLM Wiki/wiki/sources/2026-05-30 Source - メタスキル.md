# 2026-05-30 Source - メタスキル

## 要点

- 生成AI時代には、努力して個別スキルを積み上げるだけでは差異になりにくく、`メタスキル + AI活用` へ努力の方向を変える必要がある。
- メタスキルとは、構造を見る力、隠れたルールを見つける力、自分の価値が発揮されやすい仕組みを作る力、AIで得意分野を社会資本に変える力。
- 重要なのは、頑張ることではなく、死なない構造を先に作り、摩擦をモジュール化し、自分がプレイヤーではなく設計者になること。
- AIは答えを出す道具というより、構造化、事前検死、問いの言語化、リサーチのz軸拡張、AIチーム化、ログ化、自分のモジュール化に使う。
- `自分のモジュール化` は、作業、知能、存在をそれぞれ AI / ネットワークに接続可能な部品にすること。自分が作業するだけでなく、AIに見つけられ、選ばれ、接続される状態を作る。
- `資産を循環させる構造` は、人的・社会資本と内発的動機の循環、金融資本による時間の買収を組み合わせること。AI時代には自分が汗をかくより、AIに汗をかいてもらう構造を作る。
- `デジタル・アルチザン` は、AIと資本家がスケーラビリティを担う時代に、効率指標から降り、偏愛や非合理なこだわりを千人・一万人の意味へ高める職人的戦略。

## 主張

- これからは `努力 -> スキル獲得 -> 成果` ではなく、`努力 -> メタスキル + AI活用 -> 成果` のゲームになる。
- AI時代の勝ち筋は、同じ盤面で速く作業することではなく、どのゲームを選び、どのルールで戦うかを設計すること。
- 自分の作業、知能、存在をモジュール化し、AIやネットワークに発見・接続される状態を作ることが重要。
- 機能や正解がコモディティ化するほど、ナラティブや意味、偏愛、応援される理由が価値になる。
- 良い問いとは、目的地だけでなく現在地も含む問い。AIに投げる前に、誰のどんな悩み、どんな代替手段、どのレイヤーの問題なのかを言語化する必要がある。
- AIチームを運用するには、完成物だけでなく、迷い、比較、捨てた案、判断基準のログを残す必要がある。判断過程のログが、組織や個人の正拳突きを身体化する。
- 変化の激しい高周波スキルだけに投資するのではなく、抽象化、構造化、問いの設計、ゲーム変更のような低周波・長寿命の能力へ投資する。
