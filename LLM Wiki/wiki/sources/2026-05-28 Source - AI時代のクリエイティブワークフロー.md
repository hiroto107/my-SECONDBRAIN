# 2026-05-28 Source - AI時代のクリエイティブワークフロー

## 要点

- 生成AIが制作工程と必要スキルを変えることを扱う記事。制作は手作業中心から、意図設定、判断、編集、協働へ重心が移る。
- 生成AIは、技術的熟練による表現制約を下げ、構想、アイデア出し、初稿作成、反復を効率化する。
- その一方で、重要になるスキルはツール操作そのものから、アイデア創出、問題解決、クリティカルシンキング、学び続ける力へ移る。
- クリエイティブの民主化を肯定しつつも、d.school系 source と合わせると、単なる効率化ではなく、何を作るかを判断する人間側の能力が焦点になる。

## 主張

- 生成AIは、プロでなければ試せなかった表現や実験へのアクセスを広げる。
- 日常的な作業や初期ドラフトが自動化されるほど、人間は「ただつくり出す」ことや、より高次の問題解決に時間を使える。
- 将来のクリエイターには、特定ツールを固定的に覚える力より、AIの使い方を更新し続ける学習能力が求められる。
- ただし、効率化の語りだけでは、創造的主体性や摩擦の価値が抜け落ちる。`Easy Button` 論と合わせて読む必要がある。
