# 2026-04-20 Source - ホラーとデジタルネイチャー

## 要点

- この source は、`デジタルネイチャー` と `日本ホラー` を接続し、霊性、情報、身体、畏れを再定義しようとする。
- 日本ホラーの背景には、`神道的アニミズム` `仏教的空性` `幽玄` `陰翳` があり、見えないものへの畏れを支えていると整理される。
- デジタルネイチャーは、自然 / 人工 / 情報 / 身体の境界を流動化し、ホラーの舞台を `スクリーンの内側` から `日常空間そのもの` へ拡張する。
- AR/VR/MR やデータ化された場は、`霊性を帯びた情報環境` として読め、日本ホラー的な `日常侵食` と高い相性を持つ。
- 恐怖は単なる脅威ではなく、`畏れ = 尊崇` を含んだ感情として再定義されうる。

## 主張

- デジタルネイチャー時代のホラーは、怪物表現の高度化ではなく、身体境界と現実認識の再編を主題にするべきである。
- 日本ホラーは、情報技術時代の存在論を考えるための美学・哲学として再読可能である。
- `自己崩壊の予感` や `自己が怪異を生成するかもしれない感覚` が、次世代ホラーの重要な軸になる。
