# 2026-07-02 Source - noteのはじめかた もっとも大事なこと

## 要点

- note を始める人にとって最重要なのは、PV、収益、フォロワー数ではなく、創作を楽しみ続けることと、ずっと発表し続けること。
- 名文や超大作を狙って手が止まるくらいなら、短文、駄文、ラクガキ、悪ふざけでもよいので気軽に出す。
- 創作は筋トレやランニングのような長い旅であり、一時的な集中より日常生活の一部にすることが重要。
- ノウハウが面倒さや辛さを増やすなら、違うアプローチを取るべき。楽しく手を動かせることが優先される。

## 主張

- 創作の初期段階では、成果指標より継続条件を守るほうが重要。
- 表現力やファンは、発表し続けているうちに後からついてくる。
- 創作を続けるためには、完成度よりも発表ハードルの低さ、楽しさ、日常化が必要。
