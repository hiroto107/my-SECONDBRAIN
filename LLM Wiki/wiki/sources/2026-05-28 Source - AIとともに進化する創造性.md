# 2026-05-28 Source - AIとともに進化する創造性

## 要点

- AI時代のデザインスキルとして、適切な自動化、ループへの参加、選択の影響認識、中程度の流暢さを示す記事。
- 創造プロセスのどこに関与し続け、どこを自動化するかを判断すること自体が新しい創造スキルになる。
- AIとの創造は、命令と結果の一回転ではなく、質問し、耳を傾け、応答し、調整する相互作用ループとして捉えられる。
- 確率的メディアを扱うほど、自分の指示、枠組み、応答、編集がプロセスにどんな影響を与えたかを認識する必要がある。
- AIで映画的な映像を作れても、映画の文法、制約、歴史、感情の作り方を知らなければ、響く作品にはならない。媒体への「中程度の流暢さ」が必要。

## 主張

- 適切な自動化とは、重要な意思決定に意図的に関わり続けることを選ぶ技術である。
- AIをスロットマシンのように扱うと偶然の当たりに依存するが、独自の挙動と質感を持つ新しいメディアとして扱うと、自分の思考を深める空間になる。
- 創造者はすべてを制御する必要はないが、自分の選択が何を促し、形づくり、再考させたかを意識する必要がある。
- AIは人間の創造性を奪うものではなく、実験と好奇心を強化する `電動自転車` のように使える可能性がある。
