# 2026-04-20 Source - アートを学ぶ：多神教的な落合陽一と一神教的なチームラボ

## 要点

- この source は、落合陽一とチームラボを `多神教的世界観` と `一神教的世界観` の対比として読む。
- 落合陽一は、計算機自然を自然の延長として捉え、関係性のなかで更新される自己を示す側に置かれる。
- チームラボは、アルゴリズム的な統制と境界消失を通じて、個をシステムへ統合する側として描かれる。
- 両者の対比は、AI時代の `人間とAIの共生` と `人間とAIの統合` という二つの道を考えるための図式になっている。
- 最後には `間` の思想を第三の道として置き、対立を超えた動的統合の可能性が示される。

## 主張

- AI時代の存在論は、便利さの問題より、`何者であるか` と `何者でもない` のあいだをどう生きるかの問題である。
- 落合陽一とチームラボの比較は、現代アート論であると同時に、生き方の比較でもある。
- 重要なのはどちらが正しいかではなく、複数の世界観をどう往復し、どのような生き方を選ぶかである。
