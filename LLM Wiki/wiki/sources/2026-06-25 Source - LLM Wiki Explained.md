# 2026-06-25 Source - LLM Wiki Explained

## 要点

- 生のメモ・PDFを一度AIでWiki化し、質問のたびに生データを探し直さない。
- フォルダ構成は raw/（素材）＋ wiki/（整理済み知識）＋ schema（設計の核心）。
- 3操作：Ingest / Query / Lint。RAGは都度検索、LLM Wikiは要約・相互参照がコンパイル済み。
- 個人規模100〜200ソースがスイートスポット。データ主権を手元に保てる。

## 主張

- チャットボットはセッションごとにリセットされ、知識は蓄積しない。
- 優秀な研究者と同様、AIにも「成長し続ける知識ベース」が必要。
- File over app——MarkdownとGitで持つ知識が資産になる。
