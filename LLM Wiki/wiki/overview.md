# overview

この page は、`LLM Wiki` の現在の全体像を圧縮して持つための俯瞰ノート。

## 現時点の焦点

この Vault から見える主題は、おおむね次の交差点にある。

- `AI` を単なる道具ではなく、存在論や自然観を揺らすものとして捉えること
- `AI` を個人相手の assistant ではなく、複数人の協働を媒介する facilitator として捉えること
- `アニミズム` を、日本文化だけでなく AI や人工物との関係を考える存在論として扱うこと
- `デジタルネイチャー` を、アニミズムと AI をつなぐ現代的自然観として扱うこと
- `日本文化` を表層的な和風記号ではなく、世界の見方そのものとして扱うこと
- `ホラー` を怪物の視覚化ではなく、気配、余白、侵食、境界崩壊の設計として扱うこと
- `怨霊` `御霊` `鎮魂` を、日本的恐怖と共同体の処理様式を読むための軸として扱うこと
- `XR` やメディア技術を、現実の侵食経路として接続すること
- `AI時代の自己` を、存在論だけでなく制作、仕事、コミュニティ形成まで含む生き方の問題として扱うこと
- `AI` の進化を「仕事が奪われるか」だけでなく、主体性、学習方法、制作重心の再配置として扱うこと
- 主観的タスクでも、批評分離・盲検評価・知識層接続で品質を上げる運用設計として扱うこと
- `Jホラー` を、日本文化の深層と AI / XR 時代の存在論をつなぐ実践文法として扱うこと
- `多神教的世界観` と `一神教的世界観` の対比を、AI時代の自己とシステム観の比較軸として扱うこと
- `日本文化` を保存対象としてだけでなく、意味生成と価値形成の資源として扱うこと
- `メタスキル` を、AI時代に個別スキルを積むだけではなく、構造を見てゲームをずらす生存戦略として扱うこと
- `メタスキル` を、作業・知能・存在のモジュール化、AIチーム術、資産循環、少人数の意味づくりまで含む価値循環設計として扱うこと
- `リミナルスペース` と `ロア` を、Jホラーや民俗学的世界観を設計するための中核概念として扱うこと
- `ビル格` を、建物の一次情報を LLM Knowledge 化し不動産価値を再設計する実践概念として扱うこと
- `AIの上司になる` ことを、AIと作業量で競うのではなく、問い、目的、意味、欲望、現場情報をAIに注入する役割として扱うこと
- `AI時代の創造性` を、生成の容易化ではなく、意図、摩擦、好奇心、実験、選択、媒体文法、身体性を再配置する問題として扱うこと
- AI生成物の価値を、出力の見た目だけでなく、起源、生成過程、物質性、データ、労働、環境負荷、人工物としての存在形式から扱うこと
- `知的発酵` と `忘却` を、AIの即時生成に対する人間側の時間差・選択・編集の技術として扱うこと
- `継続的発表` と `環境選択` を、創作や職能が長く続く条件として扱うこと

## 作業仮説

### 仮説1

日本ホラーの強さは `怪物のデザイン` よりも、`見えないものが日常へしみ出す設計` にある。

### 仮説2

`AI` `XR` `ログ` `通知` `生成された声` のような現代的メディア要素は、Jホラーの文法と高い相性を持つ。

### 仮説3

`アニミズム` `多神教的世界観` `間` `幽玄` `陰翳` は、美学であるだけでなく、AI時代の存在論を記述するための語彙にもなりうる。

### 仮説4

日本各地の怪異、因習、地名伝承、土地の記憶は、ローカルな文化資源であると同時に、現代技術で再構築しうる IP の種でもある。

### 仮説5

AI の価値は単独生成だけではなく、`議論の要約` `対立の整理` `共有記憶の保持` `次の artifact への変換` といった協働の運営機能にもある。

### 仮説6

日本的怪異の強さは、怨霊を単なる敵として消すのではなく、祀り、鎮め、守護へ反転させる文化構造にある。

### 仮説7

日本コンテンツの強さの一部は、自然、妖怪、道具、人工物、AI を同じ連続体のなかで生きた存在として扱えるアニミズム的世界観にある。

### 仮説8

AI時代の差異は、`情報量` や `汎用制作能力` よりも、`身体性` `一次情報` `世界観` `物語化` `関係性形成` の束に移っていく。

### 仮説9

生成AI時代の価値は `大量に書くこと` より、`読み抜くこと` `選ぶこと` `配置すること` `情報環境を設計すること` に移りつつある。

### 仮説10

`Jホラー` の本質は恐怖ジャンルであることより、`気配を設計し、見えないものの侵食を体験化すること` にある。

### 仮説11

`多神教的世界観` と `一神教的世界観` のあいだの揺れは、AI時代における `共生` と `統合` のあいだの揺れでもある。

### 仮説12

AI時代における日本の強みは、効率の競争より `意味をつくること` `価値を感じさせること` `文化資源を再編集すること` にある。

### 仮説13

AI時代の個人戦略は、個別スキルの熟練より、`メタスキル` によって戦うゲーム、問い、仕組み、ナラティブを設計する方向へ移る。

### 仮説13b

AI時代の個人価値は、単にAIを使えることではなく、作業・知能・存在を [[LLM Wiki/wiki/concepts/自分のモジュール化]] し、[[LLM Wiki/wiki/concepts/デジタル・アルチザン]] 的な偏愛を少人数の意味へ変え、人的資本・社会資本・金融資本・時間資本が循環する構造を作れるかに移る。

### 仮説14

Jホラーの怖さは、怪物より先に、`リミナルスペース` に生じる分類不能な不安が `気配` となり、共同体の語りを通じて `ロア` 化する過程にある。

### 仮説15

ビル格の価値は LLM 性能の向上ではなく、建物の魂・心・記憶を一次情報として構造化し、「人が動き、お金が動き、関係性が変わるか」で検証される。

### 仮説16

AI時代に人間が残す価値は、作業量や正解生成ではなく、AIに渡す初期条件、欲望、意味づけ、ノイズ、現場情報を決めることに移る。

### 仮説17

AI時代の創造は `easy button` 化すると薄くなる。AIで出力や実験が容易になるほど、人間側の価値は、どこに摩擦を残すか、何に反応したか、何を選んだか、どの身体性・0次情報・媒体文法で定着させるかに移る。

### 仮説18

AI生成物の違和感は `機械が作ったから` だけではない。本物性、作者性、生成過程、コピー可能性、倫理、環境負荷が重なるため、作品評価は出力の表面から [[LLM Wiki/wiki/concepts/人工物の美学]] へ広がる。

### 仮説19

AI時代の創造性は、速く生成することだけでは薄くなる。強い問いや作品は、入力を [[LLM Wiki/wiki/concepts/知的発酵]] させ、不要な情報を [[LLM Wiki/wiki/concepts/忘却]] し、身体や第一次的現実を通して残ったものを編集したときに立ち上がる。

### 仮説20

創作や職能は、才能や説得力だけでは長続きしない。[[LLM Wiki/wiki/concepts/継続的発表]] できる低摩擦な型と、価値が通じる [[LLM Wiki/wiki/concepts/環境選択]] が揃うほど、偏愛や技術は資産化しやすい。
