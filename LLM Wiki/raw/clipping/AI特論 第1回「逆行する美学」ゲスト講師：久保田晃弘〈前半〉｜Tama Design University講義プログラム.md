## ひとことで

生成AIは「次の単語を予測する技術」だが、それだけでは説明できないほど複雑で、文化も大きく揺れている。

久保田は、**今の技術的現状**と**それに対する文化的反動**を整理したうえで、**歴史を逆行して辿る**ことで、生成AIの美学がどこから来ているのかを見よう、と提案している。

講義タイトル「逆行する美学」とは、**生成AIの精神史を過去に遡って読み解く**という意味。

---

## この講義の問い

- なぜAIはこう描くのか？
- 創造性の主体はどこにあるのか？
- 作者・作品という概念は普遍か？
- AIを「道具」として使っているのか、「代理人」に指示しているのか？
- AIの電力・通信コストは地球環境にどれだけ負荷をかけているか？

## Part 1: 技術的な現在 — LLMとは何か

### 「予測しているだけ」は半分正しい

LLMは本質的に **次のトークンを予測する** 仕組み。  
ただし、その裏には Transformer、Attention（文脈を読む仕組み）、大量のパラメータ、温度（temperature）など、**数十年分の研究の蓄積** がある。

- **温度を上げる** → 候補が広がり、意外性が出る（ハルシネーションも増える）
- **温度を下げる** → 決まった答えに収束する

「予測だけ」と言うのは正しいが、**単純ではない**。

### AIのカンブリア爆発

生物進化の「カンブリア爆発」のように、2022年前後からAIアーキテクチャが **爆発的に多様化** している。

- [LLM Architecture Gallery](https://llm-architecture.info/) のように、モデル構造は百貨店のように増え続けている
- 生成AIは **1つの確立した技術** ではなく、研究者・ベンチャーが切磋琢磨する **非常にアクティブな分野**

### 2つのパラダイムシフト

| 方向 | 内容 |
|---|---|
| **スケーリング（力）** | データ量・パラメータ・計算量を増やして性能を上げる |
| **効率化（省エネ）** | 計算量を減らし、端末で動く・省電力のモデルを作る |

後者の例:
- **MoE（Mixture of Experts）** — パラメータを増やしつつ、1回の推論で使う情報量を減らす
- **1-bit LLM / 1.58-bit LLM** — 極限まで量子化しても性能が保てる → **知能密度** が上がる → スマホでも動く

### 環境問題

- 生成AIへの問い合わせ1回は、従来の検索の **数倍〜10倍のエネルギー**
- データセンター、冷却、電力供給が大問題
- **性能向上だけでなく、エネルギー効率** が次の競争軸

## Part 2: 文化的な現在 — デジタル完璧性への反動

### 性能が上がるほど、均質でツルツルしたものしか生まれない

技術者は「素晴らしい」と言うが、文化側からは **疑問の声** が上がっている。

**2024〜2025年に目立つ動き:**

| 名称 | 意味 |
|---|---|
| **Tactile Rebellion（触覚の反乱）** | 質感、ぬくもり、手触りを取り戻す |
| **Post-AI Expressionism** | AI生成物に手書きで加筆する |
| **Techno-Minimalism** | 1990年代のミニマル美学の復活 |
| **Surveillance Aesthetics** | 監視カメラ的な低解像度・高圧縮の美学 |
| **Frutiger Aero / Neo Aero** | 2000年代UI美学の再評価・極限化 |
| **Wabi-Sabi** | 生成AIの完璧さの反面教師として、錆・破れ・不均一を再発見 |

例: Red Bullのロゴに **コルクにバクテリアを繁殖させ、成長を記録し、手作業で仕上げる** ビジュアル。

### 技術と文化の緊張関係

- 技術が開発されたから **「世界が変わります」** と安直に言うのではなく
- **「ちょっと待てよ」** という文化的反動が強まっている
- 久保田はこれを **いいこと** だと考えている

### New Aesthetic（新しい美学）

James Bridle（2011）が提唱。人間的でない視点の美学:
- 監視カメラの赤外線画像
- 人工衛星のRGBチャンネルずれ
- 機械が「見ている」世界の質感

## Part 3: 2〜3年前の議論 — 美的アライメントとAIカニバリズム

### RLHF（人間好みへの調整）

LLMの学習は2段階:
1. **事前学習** — 大量データから穴埋め問題を無限に作って学習
2. **教師あり学習 / 報酬モデル** — 人間が好む答えに調整（倫理、配慮、丁寧さ）

→ 結果として **人間のシミュレーション** に近づいていく。  
「AIは別の知能」ではなく **「隣にいる別の人間」** のように感じさせる設計。

### 美的アライメントの問題

画像生成で問題になったこと:
- 報酬モデルは **統計的な平均的な美** を学習する
- 作られるものが **ビッグデータ的平均** に収束する
- 美術史を作ってきたのは **平均的でないもの**

「美的調和が芸術的表現を狭める」という批判（2023年頃）。

### AIカニバリズム（AIの友食い）

- AI生成物が再び学習データに入る → **平均的な美が増幅** されるループ
- イレギュラー・珍しいものが相対的に減る
- パーソナライズ（各自の美的嗜好に合わせる）も **フィルターバブル** 問題は同じ

### インターネットは狭い

- テック業界は「インターネットの膨大なデータで賢くなった」と言う
- しかし **触覚・味覚・嗅覚はほぼない**。視覚情報だけが肥大化
- 砂漠のライブ配信を見ても、**現地の砂漠のごく一部** しかAIは学習していない
- **生成AIができること = コンピューターができることの一部**

余談: インターネットの「重さ」は、動いている電気で **じゃがいも1個分（約50g）**、蓄積データで **砂1粒の1/10**。その重さを支えるために世界中にデータセンターを建てている。

## Part 4: 歴史を逆行する — メディアの進化

### レフ・マノヴィッチ: 「生成」ではなく「予測」

- **Generative Art** = コードで多様な出力を生む（同じ形にならない）
- **生成AI** = 文脈を読んで **次を予測する**
- 人間の脳も最大の機能は **予測**（Jeff Hawkins 等）
- だからチャットというインターフェースが成り立つ

### 画像メディアの5段階（レフ・マノヴィッチ）

1. **手動表現** — 彫刻、手書き
2. **補助デバイス** — カメラルシダ、パースpective frame
3. **記録** — 写真、ビデオ
4. **シミュレーション** — 3DCG、物理法則
5. **予測** — データセットに基づく確率的ピクセル予測 ← **今ここ**

### スマートフォンカメラ = すでにAIの世界

2010年代〜、カメラは **記録装置** から **計算写真（Computational Photography）** へ:

- HDR、バースト合成、被写体認識、背景ぼかし
- **撮ってからフォーカスを変える**
- **撮った後に物を消す・背景を変える**
- カメラ = 「不完全なデータから最適な画像を予測生成するシステム」

→ **スマホを使っている時点で、すでにAIの世界にどっぷり入っている**

### Next Rembrandt（2016）

レンブラントの絵画を学習し「エッセンス」を抽出 → 新しい審査が作れる、というプロジェクト。

2つの「アーカイブ」:
- **伝統的アーカイブ** = 集めたら終わり（本物のアウラ）
- **データセット・アーカイブ** = 集めたうえで **生成もできる**

## Part 5: さらに遡る — コンピューター文化の原点

### 1990年代: ソフトウェアテークス

- Photoshop、MIDI、データベースアート
- **「ガウシアンぼかしを3ピクセル適用するとどうなるか」** という **政策（ポリシー）** で語れるようになった
- レフ・マノヴィッチ『Software Takes Command』— ギデオン『機械化の文化史』の延長

### 分解と再構成

- ウィリアム・J・ミッチェル: デジタルメディアの特徴は **分解と再構成**
- レフ・マノヴィッチ: 数値による表現、モジュール性、自動化、可変性、トランスコーディング
- **生成AI = この流れの延長線上**。突然変異ではない

### 1960年代: コンセプチュアルアート

- ソル・ルウィット: **「アイデアが芸術を作る機会。実行は形式的手続きに過ぎない」**
- ウォール・ドローイング — 16パターンの組み合わせで壁面インストレーション
- **人間の手による物理的描写をしない美術** は、20世紀ずっと試されてきた

### バウハウス / ヴフテマス

- カリキュラムの核心 = **分解と再構成**
- 点・線・面・色彩・空間・質感 → モジュールを組み合わせる
- **生成AI = バウハウスがやった視覚表現の分割・再構築を、大規模データセットと高速計算でやる**

### 20世紀モダニズム

- ダダ、レディメイド、断片化の美学
- アルプの「床に落とした紙の配置」≒ データセットから確率的に画像を生成
- **Outpainting**（絵画の外側をAIに予測させる）= 断片絵画との類似

## Part 6: 作者性とロマン主義

### ロマン主義が発明したもの（18世紀〜）

| 概念 | 内容 |
|---|---|
| **アーティストの内面** | 自分の中にあるものを描くべき（フリードリヒ） |
| **創造性** | 模倣ではなく、内面から溢れ出る独自のエネルギー |
| **天才** | 無から想像する |
| **想像力** | 神聖化された個人の能力 |

→ **「AIには魂がない」「想像性が不在」** という感覚は、**ロマン主義的価値観** に由来する。

### 星新一コンテスト問題

- AI生成小説の応募が増加 → 審査員が辞退
- 問題は **レギュレーション** ではなく **ロマン主義的な作者観**
- 重要な問い: 作者がAIだと知った後、**感動は変わるか？**

### 古代ギリシャ: テクネ（techne）

- 医学、建築、音楽、絵画、料理、政治… **あらゆる学習された技能**
- 価値 = **内面の表出** ではなく **ルールに従った模倣と熟練**
- **創造（creation）は神のみ**。人間は **模倣・再現** が使命
- ヘテのファンベイク（世界の再現）を **別の目で見る** と、今の生成物も理解できる

---

## Part 7: 逆行美学のまとめ — 3つの立場

| 立場 | 内容 |
|---|---|
| **人間中心主義** | AIは道具。作者性は人間に帰属する |
| **ポスト構造主義** | 作者は消え、作品は文化的断片の統計的産物（バルト「作者の死」） |
| **テクノアニミズム** | AIに意図・主体性を認める（ピグマリオン効果） |

### 久保田の見立て

- 生成AIは **破壊** ではなく、**意味の層を1枚ずつ剥がして再検討する機会**
- 玉ねぎのように歴史の上に積み重なった **意味のレイヤー** を逆行して読む
- **作者の死（バルト）** が、生成AI時代に初めて **機能する概念** になるかもしれない
  - エージェンシーの分散
  - ベンジャミンの「アーカイブ・プロジェクト」の続きができるかも
- **歴史を救済し、文化継承する** ことが、生成AI時代の美学の重要課題
