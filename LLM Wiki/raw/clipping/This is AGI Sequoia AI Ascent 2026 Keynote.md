# This is AGI: Sequoia AI Ascent 2026 Keynote

**出典:** [YouTube](https://www.youtube.com/watch?v=LRo33rnv6rQ)  
**登壇:** Sequoia Capital — Pat Grady, Sonya Huang, Konstantine Buhler  
**イベント:** Sequoia AI Ascent 2026

---

## この講演の結論

Sequoia は、**2026年時点で実用上のAGIが始まった** と主張している。

技術的なAGIの定義はここでは議論しない。ただ、**エージェントに仕事を任せ、失敗から回復し、完了まで粘り続けられる** なら、ビジネスの現場ではそれはもうAGIと言っていい、という立場だ。

これまでのAIは「少し速くなる馬」。いま来ているのは「仕事のやり方そのものを変える車」。

---

## Part 1: 全体像 — Pat Grady

### テクノロジーの波は積み上がってきた

シリコンベースのトランジスタ → ネットワーク → インターネット → ソーシャル・クラウド → モバイル → **AI**

どの波も前の波の上に乗っている。計算力、帯域、データ、人材が揃って初めて、今の瞬間が来た。

### AI波がこれまでと違う3つの理由

**① 最大の波**

- これまでのクラウド移行で、ソフトウェア市場は約3500億ドル → 6500億ドルに拡大し、そのうちクラウドが約4000億ドル。
- 今回新しく開いたのは **サービス市場**。
- 10兆ドルは丸めた数字。5兆でも50兆でもあり得る。
- 米国の法律サービスだけで4000億ドル。1業界・1地域で、ソフトウェア市場全体と同規模。
- **ソフトウェアとサービスの両方を食う、初めての波。**

**② 最速の波**

- クラウド・モバイル・AIで、売上10億ドル超に到達した企業が次々と現れている。
- 空白地帯は急速に埋まっている。

**③ 通信革命ではなく、計算革命**

- インターネット、クラウド、モバイル → **情報の配布（communication）** の革命。
- AI → **情報の処理（computation）** の革命。
- 言葉の違いに見えて、波の形が根本的に違う。
- 床が毎日動く。基盤モデルの新能力が出るたびに、全員の足元が変わる。

### 3つの転換点

| 時期 | 出来事 | 意味 |
|------|--------|------|
| 2022年11月 | ChatGPT | 事前学習（pre-training）の力が世界に見えた |
| 2024年頃 | o1 | 推論時計算（inference-time compute）という第2のスケーリング法則 |
| 2026年 | Claude Code / Opus 4.5→4.7 | 長期タスク型エージェントの力 |

1→2→3は連続に見えるが、**2と3の間には不連続な変化がある**。Sequoia はここを **AGI** と呼ぶ。

> 商業的・実用的・機能的に見て、エージェントに仕事を任せ、失敗から回復し、完了まで続けられるなら、それはAGIに等しい。

### 速い馬 vs 車

- **速い馬（faster horses）:** 生産性が10〜40%上がる。仕事のやり方は変わらない。
- **車（cars）:** 生産性が10〜40倍。仕事の性質、組織の性質そのものが変わる。

**車は、もう来た。**

### So what?（だから何？）

Sequoia創業者 Don Valentine の問いへの答え:

- 数ヶ月前から **レースは始まっている**。
- 車の乗り方も、作り方も、馬とは根本的に違う。
- 誰も全答を持っていない。だからこそ集まる必要がある。
- 商業的には **10兆ドル規模** が争われている。
- ラボは tech-out（技術から）。スタートアップは customer-back（顧客から）。

### モデルの上に作る企業へのアドバイス: MAD

「怒れ（get mad）」— 本当に怒る必要はない。**MAD** という頭字語。

**M — Moats（堀）**

- 計算革命では、下（最新技術）ばかり見たくなる。
- でも堀を作るなら **上（顧客）** を見るべき。
- 顧客は能力ほど速く変わらない。今日作ったプロダクトは明日 irrelevant になり得る。
- **顧客に深く巻き込む** 方が durable。
- プロダクト・技術も insanely important。基本は best product wins。

**A — Affordance（示唆性）**

- デザイン用語。ハンマーは説明なしで使い方がわかる。
- Claude Code は insanely powerful だが、Fortune 500 の平均社員にターミナルを開かせても進めない。
- Anthropic を批判しているわけではない。**上に乗る人のチャンス**。
- 特定顧客・特定問題向けに **最短経路** を作れ。

**D — Diffusion（普及ギャップ）**

- 能力が生まれる速度 >> 大企業に普及する速度。
- 基盤モデルが1日でも先に進むほど、ギャップは広がる。
- **このギャップがアプリ層の機会。**

> レースの格言: 晴れの日に15台追い抜くのは無理。雨の日なら追い抜ける。  
> 今は能力の豪雨。リードは安全ではない。**誰でも勝てる。**

## Part 2: いま起きていること — Sonya Huang

### 2026年のAI = エージェント

2022年、AutoGPT や BabyAGI は GitHub で一晩で話題になった。GPT-3 にツールを渡し、ループで回してゴールに向かった。 promising だったが、何度も失敗を繰り返すだけ。**かわいいが使えない。**

エージェントが来ることは分かっていた。モデルがまだ早すぎた。

**年始あたりから一気に変わった。** エージェントが everywhere で、実際に動いている。

特に2つが home run:
- **Claude Code** — 技術者向け
- **OpenClaw** 系 — スマホがあれば誰でも

**誰でもエージェントを作れる時代。**

### エージェントの定義

> 環境を認識し、行動を選び、目標に向かって自律的に進むシステム。

3つの機能:

1. **推論・計画** — その場で考える頭脳
2. **行動** — ツール、検索、書き込み、コンパイル（手足）
3. **反復・持続** — 長期タスクで粘り続ける力

**Agency = やり遂げる能力。**

### 3つの構成要素の進化

**モデル（脳）— 最重要**

- 複雑タスクで脱線せず進められる時間が、1年前は **数十分** → 今は **数時間**。
- 長期タスクで performance を sustain できるようになった。

**ツール（手足）**

- ターミナル、Slack、Web検索、computer use など。
- 人間向けに20年かけて作ったツールが、エージェントにもそのまま使える。
- **SaaS is dead ではない。** エージェント利用者が増えれば、ツールの価値は爆発する。

**ハーネス（持続性）**

- タスクに留まり、適応し、続ける仕組み。
- RL gym で「運転教習」。機械工学、デザイン、金融など各領域で性能向上。
- **機械が機械を作る** 自己改善の兆しも（Karpathy の研究: 2時間で GPT-2 級モデルへ自律改善）。

### エージェント性の段階（コーディング例）

| 段階 | 内容 |
|------|------|
| Tab補完（2023） | 人間の横で少し助ける。incrementally useful、非変革的 |
| Agentic Development | 人間がエージェントに指示、チーム管理 |
| Async / Background Agents | 裏で複数エージェントが自律実行。**量ではこちらが主流になる見込み** |
| Dark Factories | 人間レビューなしで本番投入。サイバーセキュリティ等で既に production 実例あり |

> 横で手伝う助手 → 管理が必要なインターン → 自分で管理するインターン → oversight なしで prod に出せるインターン

### Services is the new software

Pat が長年言い続けてきたこと。Julian の記事でも。**今、本当に起き始めている。**

| 分野 | エージェントが担う例 |
|------|----------------------|
| 医療 | ゲノム解析、個別治療提案、処方、臨床試験推薦 |
| 法律 | 契約交渉、訴訇、和解 |
| 科学 | 未解決問題、新超伝導体の発見 |
| 個人 | メール、カレンダー、家計、税務 |

**人間 vs エージェント:**

| | 人間 | エージェント |
|---|------|-------------|
| スケール | 難しい | 計算で無限 |
| メンテ | 幸福維持が大変 | 低メンテ |
| コスト | 給与 | トークン（一般に安い） |
| 知能 | 今はまだ上 | bitter lesson が押し寄せる |

人間が仕事を失う話ではない。**適応力** は人間固有。ただしエージェント導入は経済合理性とビットのスケーラビリティから、前例のない速度で進む。

### これから起きうること

- エージェント同士の商取引・支払い
- エージェント同士の交渉
- サイバーセキュリティを守るエージェントの群れ

**世界は extremely quickly おかしくなる。**

### 100年 → 100日

誰もが「AIで insane なタイムライン圧縮」の例を知っている:
- Zed の Nathan: 3年プロジェクトを休暇中に Claude Code だけで
- Bret Taylor: Sierra を週末で rebuild
- Notion: 800万行を6週間で rewrite

少数しか見ていないのは、**この圧縮を重ね合わせたとき** の世界。

> 100年かけて想像していたものが、エージェントのおかげで **100日** で可能になる。

## Part 3: これから — Konstantine Buhler

### 物理的仕事 vs 認知的仕事

- **物理:** 仕事 = 力 × 距離。Pony Express の荷物、Falcon 9 の衛星。
- **認知:** ピタゴラスの定理、DeepMind のタンパク質折り畳み。意識的な思考。

違う種類の仕事だが、**革命のパターンは同じ。**

### 産業革命の再来

**物理的仕事:**
- 人類史の大部分、人間・動物の筋肉が担った。
- 水力・風力 → 蒸気 → 内燃 → 電気。
- **2026年、人間向け物理仕事の99%超は機械が担う。**

**認知的仕事:**
- 長い間、地球上の思考のほぼ全部は人間。
- 電子計算以降、常時兆単位の計算が人間のために動いている。
- **近い将来、地球上の認知の99.9%は機械が担う。**

> 認知革命は産業革命と同型。ただし **はるかに大きく、はるかに速い。**

---

### 未来を理解する4つのストーリー

#### ① アルミニウム = 知能

19世紀、ワシントン記念塔の頂上には世界で最も貴重な金属 **アルミ** 100オンスを載せ、Tiffany's に展示した。

数十年後、電気分解（electrolysis）が発明され、アルミはキャンディ包装やサンドイッチ包装に使われ、捨てられる。

- **アルミ = 知能**
- **電気分解 = 人工知能**

博士級スキルも、一瞬で呼び出し、使い捨てできる世界へ。

#### ② エイリアン・デザイン（異星人の設計）

今の世界は人間の認知に最適化されている。

2006年、NASA が衛星アンテナを最適化。従来は美しい幾何学対称。今回は進化アルゴリズム（RL に似る）に任せた。結果は人間の直感と異なるが **dramatically more productive** な形状。

AI がチップ、車、建物を設計すると、**人間には直感できない形** になる。オープンマインドが必要。

#### ③ 新しい科学の誕生

産業革命初期、Newcomen や Watt は試行錯誤（tinkering）で内燃機関を改良。120年後、カルノーが **熱力学** を形式化。

AI も今は tinkering 段階。理解されている科学に見えて、まだそうではない。

- 数十億ニューロン、兆トークン。
- 将来、熱力学級の **新しい基本科学** が生まれるかもしれない。この部屋の誰かが。
- 高校で教わるレベルになる。AI の mastery にも、**意識の理解** にもつながる。

#### ④ 非合理の芸術（The art of unreason）

2万5000年、芸術は写実へ向かった。洞窟壁画 → エジプト → ギリシャ → ルネサンス。

写真（daguerreotype）が登場。「絵画は終わった。機械の方が上手い。」

人間の反応:

> この芸術の目的は、目が見た現実を捉えることだったのか？  
> それとも、心と魂が感じた現実を捉えることだったのか？

印象派、表現主義、キュビズム、ネオ表現主義 — 人間は **非合理・非写実** へ進んだ。

プロタゴラス「人間は万物の尺度」— 真空では何も価値を持たない。アルミも、芸術も、知能も。**人間の体験** が価値を与える。

> **AIは仕事をする。AIは仕事をするだろう。  
> だが、なぜそれに意味があるか、なぜ気にかけるか — それを与えるのは人間のつながりだけ。**

## 締め

10年後、仕事は劇的に変わる。

変わらないのは **今日隣にいる人との関係**。それが今日から価値になる。

AI Ascent で隣の人とつながり、**人間らしさ** に身を委ねろ。
