# AIで作った映画を「実写映画」と呼ぶべきなのか？ まとめ

[元動画（西野亮廣 ライブ配信）](https://www.youtube.com/watch?v=dIIVQ4kM7lY)

## 一言でいうと

**西野亮廣は、AIで作った『煙突町のプペル』を「実写映画」とは呼ばない。「フルAI」作品として別物として見せる。ただし大事なのは、AI作品を単体の売り物にすることではなく、物語・教育・イベント・グッズ・コミュニティへ人を招き入れる「入口」として設計すること。**

---

## 1. タイトルの核心：「実写」と呼ばない

6/10の**ショートショートフィルムフェスティバル・アジア2026**（Lキューブ渋谷）で、**AI版『煙突町のプペル』の冒頭3分**が上映される。

西野の言い方：

> **「実写AIのやつは、実写って言わないよな。フルAIなんかな。」**

- 従来の実写映画（人間が演じる）とは**別カテゴリ**
- フェスチケットは**売り切れ**
- 6/28の国際フォーラム上映の**エンディングでも流す方向**で交渉中（超大型19mスクリーン）

**→ AI生成映画を「実写」と混同しない。新しい表現形式として「フルAI」と位置づける。**

---

## 2. AI作品は「入口」として設計する

この配信で一番重要なのは、AIで作った映像を「実写」と呼ぶかどうかよりも、**AIで誰でも映像や絵を作れるようになる世界で、何が差になるのか**という話。

これからAIで映像や絵を作れる人はどんどん増える。すると、「AIで作りました」「すごい映像です」「綺麗な絵です」だけでは、すぐに埋もれてしまう。制作そのものの価値は下がり、差がつくのは**その作品をどこに繋げるか**になる。

たとえば西野は、AI版『煙突町のプペル』を単体の映像作品として終わらせていない。ショートショートフィルムフェスで冒頭3分を見せ、東京国際フォーラムの大応援上映にも繋げようとしている。さらに、子供たちの招待、クラファン、アートポスター、グッズ、地域上映、ボランティア、コミュニティまで繋げている。

つまり、AI作品を「売り物」として見るのではなく、**誰かがその世界に入るための入口**として設計している。

自分がAIアートを作る場合も、綺麗な絵を作ることだけが目的ではない。その絵を見た人が、次にどこへ進むのか。物語を読むのか、イベントに来るのか、グッズを買うのか、子供たちの支援に参加するのか、コミュニティに入るのか。そこまで設計して初めて、AI作品は埋もれずに意味を持つ。

| 繋げる先   | 意味                  |
| ------ | ------------------- |
| 物語     | 世界観やキャラクターに入ってもらう   |
| 教育     | 子供や地域の学びに繋げる        |
| イベント   | 応援上映・祭り・地域上映に展開する   |
| グッズ    | 手元に残る体験へ変える         |
| コミュニティ | ファン同士が参加・運営できる場所にする |

## 7. その他の話題

**「声が小さい人」問題（西野の持論）：**
- ボランティア・スタッフは**声大きい人限定**
- 声小さい人は周囲にストレス → 「優しくない」
- タレントの声は聞きやすい。素人YouTube出演者は聞きづらい
- 島根の方は県民性で声が小さい（4人に1人名前聞き取れなかった）

**IP戦略：**
- 『煙突町のプペル』は**IP育成に10年全振り**
- エンタメ化 → グッズ → イベント → 民営化上映、と段階的に拡大

## 実践的な示唆

1. **AI映画の呼び方** ─ 「実写」と混同せず「フルAI」など新カテゴリとして扱う
2. **AI作品は入口にする** ─ 物語・教育・イベント・グッズ・コミュニティへ繋げる
3. **綺麗な絵だけでは埋もれる** ─ 見た人が次にどこへ進むかまで設計する
4. **IPは10年単位** ─ 映画 → グッズ → イベント → 民営化と段階的に広げる
5. **コミュニティ上映の可能性** ─ 78,000円から地域・学校で開催できるモデル
6. **応援上映の本質** ─ 初見でも周囲の温度に合わせず飛び込む。声を出す
7. **コミュニケーション** ─ 相手のことを考えた「聞きやすい声」は基本スキル
